# 岗位 JD 分析系统

截图 → 自动提取岗位信息 → 联网搜索公司 → 输出「公司在做什么」「公司需要什么样的人才」。
多个岗位分开保存，自动按岗位类型（技术负责人 / 算法 / 后端 / 产品……）分组。
单机运行，数据只存在本地。

![技术栈](https://img.shields.io/badge/stack-HTML%20%7C%20CSS%20%7C%20JS%20%2B%20Python-000000)
[![GitHub](https://img.shields.io/badge/GitHub-wzqfwanj%2Fjob--jd--analyzer-181717)](https://github.com/wzqfwanj/job-jd-analyzer)

- 前端：原生 HTML / CSS / JS，极简界面，明暗双主题
- 后端：Python 标准库（零第三方依赖，无需 `pip install`）
- AI：DeepSeek（视觉提取 + 综合分析），联网搜索走 Bing RSS

## 功能（最小实现）

- **两张截图，一个岗位**：上传「岗位 JD 截图」（必填）+「第二张截图」（选填：公司详情页，或 JD 的后续一页），AI 自动提取职位、公司、薪资、城市、经验、学历、技能标签、职责、要求、公司简介。
- **联网搜索 + 分析**：按公司名抓取 Bing 搜索结果，结合截图信息生成两块分析——
  - **公司在做什么**：主营业务、产品、技术方向、发展阶段；
  - **公司需要什么样的人才**：结合公司方向与 JD 的 4~6 条具体结论。分析附原始搜索来源链接，可点开核对。
- **多岗位分开保存**：每次上传都生成独立岗位记录，随时继续添加，自动按岗位类型分组，可折叠浏览。
- **识别结果可修正**：公司名/职位识别不准时，在详情页点「修正信息」修改，再点「重新分析」按新公司名重新搜索。
- **明暗双主题**：默认跟随系统，可一键切换并记住选择。
- **失败可重试**：截图无法识别、网络失败等会在岗位卡片上显示原因，点「重新分析」即可。

## 环境要求

- Windows 10 / 11（或任意支持 Python 的系统），Python 3.10+（开发环境 3.12）。
- 无需安装任何第三方包；只需要一个 **DeepSeek API Key**（<https://platform.deepseek.com> 注册后在「API Keys」新建）。
- 需要联网（DeepSeek 接口 + Bing 搜索）。截图会上传给 DeepSeek 用于识别，不接受的话不要上传。

## 快速开始

1. 启动服务（任选其一）：

   ```powershell
   python server.py        # 或双击「启动.bat」
   ```

   浏览器会自动打开 <http://127.0.0.1:8600>。常用参数：

   ```powershell
   python server.py --port 8601    # 换端口
   python server.py --no-browser   # 不自动打开浏览器
   ```

2. 点右上角「设置」，填入 DeepSeek API Key，保存。

3. 点左侧「＋ 添加岗位」，上传岗位 JD 截图（和公司详情截图，选填），点「开始分析」。

4. 等待「读取截图 → 联网搜索 → 生成分析」（通常 30~60 秒），即可看到分析结果。之后可继续添加更多岗位。

## 环境变量（可选）

| 变量 | 说明 |
| --- | --- |
| `DEEPSEEK_API_KEY` | 优先级高于设置页填写的 Key |
| `DEEPSEEK_BASE_URL` | 自定义接口地址（默认 `https://api.deepseek.com`） |
| `DEEPSEEK_MODEL` | 模型（默认 `deepseek-flash`） |

## 数据存储

- 岗位与分析结果：`data/jobs.json`
- 截图原图：`data/uploads/`
- API Key：`data/settings.json`（本地明文保存，仅用于调用接口）
- `data/` 已在 `.gitignore` 中排除，不会提交到 GitHub；备份或迁移整个 `data/` 目录即可。

## 已知限制

- 每个岗位最多两张截图；JD 更长时可以截取包含「职位、职责、要求」的主页，或多截一张作为第二张。
- AI 提取可能有个别错漏（尤其是截图模糊、多张截图拼接、非标准招聘页面），可在页面上直接改公司名/职位名后点「重新分析」。
- 联网搜索依赖 Bing RSS 的公开结果，个别公司（尤其是小公司、英文公司）可能搜不到，此时分析会明确说明资料有限。
- 分析由大模型生成，仅供参考，不构成对公司的背书；有事请以来源链接为准。
- 每次分析会调用 2 次 DeepSeek 接口（视觉提取 + 综合分析），产生少量费用；同一截图重复分析会重复计费。
- 尚未验证 `deepseek-v4-pro` 的多模态能力（当前固定使用 `deepseek-flash`）。
